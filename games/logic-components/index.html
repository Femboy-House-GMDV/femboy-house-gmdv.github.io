ABOUT THE GAME

Build. Connect. Experiment.

LogicComponents is a sandbox focused on digital logic and experimentation.

Build machines by placing components on an infinite grid and connecting them together. Start with simple logic and gradually create more complex systems.

The project is being developed from scratch with a focus on freedom, experimentation and user-created designs.
